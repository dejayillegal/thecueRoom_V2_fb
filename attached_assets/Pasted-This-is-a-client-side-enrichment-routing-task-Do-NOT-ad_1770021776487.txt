GOAL:
Make Bio Link Studio behave like Linktree / Milkshake:
- Auto-detect link sources
- Show correct platform icons

–––––––––––––––––––––
STEP 1: AUTO LINK SOURCE DETECTION (NON-NEGOTIABLE)
–––––––––––––––––––––
Actions:
1. When a URL is added, detect platform by hostname:
   - spotify.com → Spotify
   - youtube.com / youtu.be → YouTube
   - soundcloud.com → SoundCloud
   - apple.com/music → Apple Music
   - bandcamp.com → Bandcamp
   - instagram.com → Instagram
   - x.com / twitter.com → X
   - default → Generic link
2. Assign:
   - platform name
   - platform icon
   - platform accent color (existing brand-safe variants)

Rules:
- Detection is client-side only
- No API calls required

Verification:
Pasting a link immediately shows the correct platform icon.

–––––––––––––––––––––
STEP 2: PLATFORM ICON RENDERING
–––––––––––––––––––––
Actions:
1. Display platform icon:
   - on each Signal Card
   - in Live Preview
2. Icons must be:
   - high contrast
   - sharp (SVG)
   - visually consistent
3. Generic links use a neutral link icon.

Verification:
Each link visually communicates its source instantly.

Rules:
- No scraping

Popular platforms show thumbnails when possible.
