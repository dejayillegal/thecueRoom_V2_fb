Implementation details — exactly what to change/create
A. New util: apps/web/src/lib/safe-fetch.ts

Implement safeFetch(url, opts):

Default timeout 10s.

attempts default 3.

Exponential backoff: 300ms * (2 ** attempt).

On ENOTFOUND / EAI_AGAIN / ECONNREFUSED / ETIMEDOUT capture error.code and error.errno and return structured { ok:false, error: { message, code, retried } }.

For HTTP non-200, read text and return { ok:false, status, textSnippet }.

On success try to return json() but if JSON parse fails return { ok:true, type:'text', text }.

Export type FetchResult = { ok: boolean; status?: number; json?: any; text?: string; error?: { code?: string; message: string } }.

B. Caching helper: packages/feeds/cache.ts

Exports readCache(sourceName, ttlSeconds) and writeCache(sourceName, data).

Use atomic write (fs.writeFileSync(temp) -> rename) to avoid partial files.

Add TTL check and lastFetched metadata.

C. Update each source file (e.g. packages/feeds/sources/swiggyEvents.ts)

Replace raw fetch(url) with:

const res = await safeFetch(url, { timeout: 8000, attempts: 3 });
if (!res.ok) {
  errors.push({ source: 'swiggy', code: res.error?.code || `http_${res.status}`, message: res.error?.message || res.text?.slice(0,300) });
  // try cache fallback:
  const cached = readCache('swiggy', CACHE_TTL_SEC);
  if (cached) return { events: cached.events, fromCache: true };
  return [];
}
const text = res.json ?? res.text;
parse text...
writeCache('swiggy', { events, lastFetched: Date.now() });
return events;

D. Update app/api/gigs/india/route.ts

New shape:

export async function GET(req) {
  const { events, errors } = await fetchAllSources({ enabledOnly: true });
  return NextResponse.json({ ok: true, events, errors }, { status: 200 });
}


fetchAllSources() runs sources in parallel with a concurrency limit (use p-limit), collects events[] and errors[]. Ensure a per-source timeout.
