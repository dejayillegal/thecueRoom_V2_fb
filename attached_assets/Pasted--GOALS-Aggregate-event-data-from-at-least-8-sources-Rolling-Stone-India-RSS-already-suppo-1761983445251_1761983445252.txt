🎛️ GOALS

Aggregate event data from at least 8 sources:

✅ Rolling Stone India — RSS (already supported)

✅ SortMyScene — event list pages

✅ DICE.fm India — API or HTML event listings

✅ BookMyShow — limited scraping (music category)

✅ SkillBox — JSON API for India gigs

✅ Paytm Insider — public REST events endpoint

✅ Zomato Live / SteppinOut by Dineout — HTML scraping

✅ Swiggy SteppinOut — fallback feed if Zomato fails

Normalize events into a common schema:

{
  id: string;
  title: string;
  date: string;
  time?: string;
  venue: string;
  city?: string;
  price?: string;
  url: string;
  source: string;
  image?: string;
  description?: string;
  genreTags?: string[];
}


Validate and enrich with AI if possible (free model or local heuristics).

Expose unified gigs via /api/gigs/list.

Cache results and dedupe by event title + date + venue.

Include ticket URLs and verify that each link is reachable (HTTP 200).

Enable admin control via /api/admin/feed-sources and /api/admin/poller.

Display gigs in a modern, performant grid UI with filters (genre, city, date).

Backend structure

packages/feeds/

  ├── sources/
  │   ├── rollingstoneIndia.ts
  │   ├── diceIndia.ts

  │   ├── zomatoSteppinOut.ts
  │   ├── swiggyEvents.ts
  │   └── index.ts
  └── normalize.ts             # Normalizes to common schema


Each source file:

Fetches the feed using axios or fetch.

Parses with fast-xml-parser or node-html-parser.

Extracts events into the normalized structure.

Adds source identifier (source field).

Returns an array of normalized events.

Caching:
Use a local cache file .local/feeds/events_cache.json and update only new/modified events.

Rate limiting:
Throttle each source to one fetch per 10 minutes per city.

Validation:

HEAD request to each event URL.

Ignore broken links or outdated events.

🧠 FREE AI ENRICHMENT

When AI_PROVIDER=none, use a local heuristic model (packages/ai/enrichEvent.ts):

Infer genreTags from title/description.

Detect duplicate venues.

Predict missing city names using keyword matching (e.g., “BLR”, “Hyd” → city names).

Auto-categorize as “Techno”, “House”, “Live”, etc.

If AI_PROVIDER=hf with HF_TOKEN, call Hugging Face distilbert-base-multilingual-cased zero-shot classifier to tag genres.
