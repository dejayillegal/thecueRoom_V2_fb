Worker — verification job processor

File: packages/ai/verification-worker.js

Should support both child_process IPC and queue file read fallback:

If TEST_MODE === 'true', simulate jobs with deterministic outcome: accept if profile URL contains test-accept, otherwise flag manual review.

Real pipeline (free-first):

HEAD request to the URL and fetch HTML (safeFetch with 10s timeout). If 200 -> valid.

Parse HTML to extract signals: username, display name, bio, follower counts (where parsable), recent release links, audio embeds (SoundCloud), Instagram posts, Bandcamp releases.

Heuristics scoring: presence of audio, multiple releases, follower count threshold OR evidence of event listings -> add points.

Use a lightweight Open-Source model or public sandbox NLU (if HF_TOKEN exists call Hugging Face stable model) to classify “authenticity”: pass/fail/uncertain. If no HF_TOKEN, rely on heuristics + metadata.

Build evidence object: { title, username, foundAudio: true|false, followerCount, lastReleaseDate, screenshots:[optional], rawHtmlSnippet }.

Make decision:

Score >= threshold → auto-approve (set user.verified=true)

Score between low-high → manual review (status=review)

Score low → reject (status=rejected)

Write job result { jobId, status, score, decision, evidence } to DB/JSON and update user row.

Worker resource control:

Limit concurrent jobs via AI_WORKER_CONCURRENCY.

Stream large downloads, abort on large content (>5MB).

Use safe JSON writing to avoid corruption.
