Title: Dashboard polish & data: real values, autoscrolling Spotlight, AI tools flows (Cover Art / EPK / Meme) — Replit-ready

Goal
----
Fix and upgrade the Dashboard so it shows real/demo data, a professional product UX, and working entry points to AI Cover Art, AI EPK Generator, and AI Meme tools. Spotlight should autoscroll (accessible + pause on hover), gigs/trending threads must show live values with skeletons while loading, and all flows must be demoable inside a Free Basic Replit (MOCK data mode available).

High-level requirements
- Dashboard widgets show real values (DB-driven or seeded demo data if DB empty).
- Spotlight = autoscrolling carousel of spotlight cards with smooth animation, accessible controls, pause on hover, swipe support on mobile.
- Gigs widget shows upcoming gigs with search/filter and "View all" link.
- Trending Threads widget shows threads with replies/likes counts and deep links to forum.
- Latest playlist / Monthly playlist (if enabled) shows embed or fallback link.
- AI Cards: Cover Art, EPK Generator, Meme Generator show live counters (usage, new templates) and clicking opens the respective tool page with query params for the selected item (deep link from dashboard).
- Dashboard must use skeleton loaders and ErrorBoundary; must look clean & professional (match theme tokens).
- Add seed/demo data generator and Replit-friendly MOCK mode.
- Tests: unit + Playwright E2E smoke for dashboard flows.
- Storybook stories for Spotlight carousel and AI Cards.

UX / Behavior details (must implement)
-------------------------------------
1) Dashboard Overview API
   - Implement GET /api/dashboard/overview that returns an aggregated JSON:
     ```
     {
       stats: { users: number, artists: number, gigsUpcoming: number, threadsCount: number, likes: number },
       spotlight: [{ id, title, subtitle, imageUrl, link, tag }],
       gigs: [{ id, title, venue, city, date, isTicketed, ticketUrl }],
       trendingThreads: [{ id, title, replies, likes, category, author }],
       monthlyPlaylist: { id, title, embedUrl, externalUrl } | null,
       aiTools: { coverArt: { usage, newTemplates }, epk: {...}, meme: {...} }
     }
     ```
   - The API should source real DB values if present, otherwise return seeded demo data when FEATURE_DASHBOARD_DEMO=true.

2) SpotlightCarousel component
   - Smooth auto-advance every 6 seconds (configurable).
   - Pause on hover and focus; resume on mouse leave.
   - Keyboard accessible: left/right arrow to navigate; focusable controls (prev/next).
   - Touch swipe support on mobile (use a small dependency or manual pointer handling).
   - Announce slide changes to screen readers (aria-live) and include accessible labels.
   - Controls: Prev/Next buttons, indicators (dots) with aria-current for active slide.
   - Each card is clickable linking to `link` (internal route or external).
   - Add optional gradient overlay and subtle parallax for professional aesthetics.

3) GigRadarWidget
   - Show next 3 upcoming gigs with date, venue, city; "View All Gigs" link to gigs page.
   - Support a filter dropdown (city) and search box inside widget (opens modal for full list).
   - If ticketUrl present, show "Book" CTA which opens in new tab; if not, CTA says "Details".
   - Skeleton loading state while fetching.

4) TrendingThreadsWidget
   - Show top 3-5 threads with replies and likes badges, category tags and time ago.
   - Include quick action buttons: Follow thread, Open thread, Share.
   - On click, navigate to forum thread (deep link).
   - If user is not allowed to view, show a locked state with CTA to sign in.

5) MonthlyPlaylistWidget
   - Show embed if embedUrl present; `iframe` lazy-loaded.
   - If embed blocked or not available, show cover image + ExternalOpenButton linking to externalUrl.
   - Add small metadata (track count, curator, published_at).

6) AIToolsBoard
   - Show three cards: AI Cover Art, AI EPK Generator, AI Meme Generator.
   - Each card shows:
     - Usage metric (e.g., "12 uses this week") from /api/ai/tools/usage.
     - New templates count and a CTA "Open" that routes to `/ai/cover-art?from=dashboard&spotlightId=...` or similar.
   - Clicking "Open" navigates to tool page and passes context (selected spotlight card or selected track) via query params or state.
   - Show quick actions: "Create now" (opens modal), "Recent creations" (opens gallery).

7) Skeletons & ErrorBoundary
   - All widgets must show skeletons while loading and friendly error cards on failure with "Retry" action.
   - Wrap dashboard with ErrorBoundary that logs to console and shows a fallback UI.

8) Clean, professional design
   - Use project tokens (spacing, colors) and 2xl rounded corners for cards, soft shadows.
   - Subtle micro-interactions: hover scale 1.02 on cards, glow on primary CTA, fade-in skeleton -> content.
   - Use `prefers-reduced-motion` respect.

9) Demo seeding & Replit mode

Developer notes & common pitfalls
--------------------------------
- Carousel timer: do not use setInterval alone; prefer requestAnimationFrame or a managed timer with cleanup to avoid leaks.
- Accessibility: ensure `aria-live` and proper roles so screen readers announce slide changes; avoid auto-opening links for screen-reader users.
- Replit demo: be strict about MOCK flags to avoid external API calls (OpenAI/Spotify).
- Data seeds must be idempotent — repeated runs should not create duplicate records.
- For mobile swipe: test on real mobile or Playwright mobile emulation.
- Keep the spotlight images optimized (max width 1200px) and use placeholders while loading.
