Quick walkthrough & design highlights (why this will satisfy your brief)

Signup & Artist checkbox

SignupModal prompts users to enter profile fields and choose isArtist. Backend stores profiles.is_artist via the Supabase profiles table. Artist flows (spotlight, event submit) are gated on that flag.

Spotlight

artist_spotlight table + admin UI to schedule featured_until and set weight. Artists request spotlight via profile UI which populates admin review queue. Spotlight displays can be prioritized using weight and featured_until.

AI Cover Art / Meme / EPK

ai_jobs queue table, worker (aiWorker.ts) calls OpenAI images API (or another model). Results saved to Supabase Storage; front-end polls job status and shows live preview. EPK export uses server-side rendering -> Puppeteer to create PDF and returns Content-Disposition so the browser triggers download.

Export / Download dialog MUST work

The Next.js API returns the PDF with Content-Disposition: attachment. The front-end should call that endpoint and handle the blob to trigger browser download (sample code included in UI tasks).

Community Forum (advanced)

Thread + post model, attachments via Supabase Storage, reactions table for likes, live updates via Supabase Realtime. AI Meme can be attached to posts/comments by creating an ai_job and appending the result to attachments when ready. Moderation enforced server-side.

News feeds & weekly curated music

news and playlists tables accept RSS/imported content. Embed spotify / soundcloud / bandcamp / mixcloud widgets via saved embed_url. Use incremental static regeneration and caching to keep this fast.

Event submission, ticket generation & scanning

Event submit API validates with Zod, does AI auto-check (OpenAI), auto-approves if confidence high else flags admin. Ticket generation path creates rsvps with qr_code Data URI; server endpoint returns PDF graphical ticket for download. Ticket scan endpoint marks attendance.

Realtime likes/views

Supabase Realtime subscriptions on reactions and views tables update UI instantly.

Notifications

notifications table + push via Realtime and email via SMTP for admin alerts.

Security & anti-promo

Server-side moderation through OpenAI moderation endpoint + regex link filters to block self-promotion outside allowed platforms (Spotify/Bandcamp/SoundCloud/YouTube). Rate-limiting and RLS (Supabase Policies) recommended.
