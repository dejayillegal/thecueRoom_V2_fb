Important constraints

Keep server-only code (Playwright worker, raw scraping) out of client bundle.

Keep poller non-blocking and limited concurrency.

Always return valid JSON from /api/gigs/india.

Use short timeouts and retries, but never block the main request longer than e.g. 5s — return cached/stale data if needed.

Provide clear acceptance checks and logging.

High-level strategy (multi-step fallback for each source)

Primary — RSS / JSON / Official API

Query official RSS, JSON, or public API endpoints first.

Use safeFetch (canonicalized) with HEAD checks for image/endpoint validity.

Secondary — Structured data (LD+JSON / microdata)

GET site landing or event pages and parse <script type="application/ld+json"> for Event objects (often present).

Parse microdata / schema.org markup as robust structured fallback.

Tertiary — Sitemap / calendar endpoints

Try /sitemap.xml, /events/sitemap.xml, /feed, .ics, or /index.xml to locate event pages.

Quaternary — AJAX / XHR endpoints (hidden JSON)

Inspect XHR network patterns for each target site (BookMyShow, Paytm Insider, Zomato Live, Swiggy/SteppinOut) and call the same JSON endpoints used by their web apps (simulate headers/cookies).

Final resort — Headless render (Playwright/Puppeteer) via server-only worker

Offload JS-rendered pages to packages/feeds/headless-worker.js (child_process.fork), parse result HTML with Cheerio.

Headless calls are rate-limited, guarded behind PLAYWRIGHT_ENABLED env var; when disabled, return cached/stale results.

Global fallbacks

If a site returns 403 or ENOTFOUND, attempt:

Change User-Agent to common desktop/mobile UA.

Add Accept-Language, Referer, Origin, and common cookies headers.

Try alternate hostnames (e.g., https://in.bookmyshow.com/ vs https://in.bookmyshow.com/), mobile subdomains.

Use the headless worker.

If still fails, mark source disabled and serve cached last-good data, and schedule re-checks at a lower frequency.

Zomato Live

Paytm Insider / Paytm

They sometimes provide events.json endpoints or /pages that embed LD+JSON. Fetch list pages and parse schema.

SortMyScene / Skillbox / DICE

Skillbox likely small — try direct HTML parse.

General parsing technique for HTML:

Use cheerio.load(html).

First try $('script[type="application/ld+json"]').map(...) and parse Event objects.

Otherwise search for known selectors .event-card, .event-list, .event-item, .event and extract fields.

For ticket/shop links, prefer canonical a[href*="ticket"] or the data-ticket-url attrs.

headless invocation (server-only API route)

// apps/web/app/api/gigs/india/route.ts (server)
import { renderPageWithHeadless } from 'packages/feeds/headless';
import { fetchBookMyShow } from 'packages/feeds/sources/bookmyshowIndia';
import cache from 'packages/feeds/cache';

export async function GET(req) {
  // return cached data immediately if fresh
  const cached = cache.read('gigs_india');
  if (cached && !req.nextUrl.searchParams.get('force')) {
    // Kick background refresh but return quickly
    poller.runBackground().catch(()=>{});
    return new Response(JSON.stringify({ ok:true, events: cached.events, meta:{ fromCache:true }}), { headers: { 'content-type': 'application/json' }});
  }

  // Otherwise run aggregator with concurrency limit
  const events = await aggregator.fetchAllSources();
  cache.write('gigs_india', { events, ts: Date.now() });
  return new Response(JSON.stringify({ ok:true, events, meta:{ fromCache:false }}), { headers: { 'content-type': 'application/json' }});
}
