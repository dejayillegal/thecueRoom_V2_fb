🔩 Core Requirements
1. Architecture

Create modular folders under:

apps/web/app/(forum)/
apps/web/app/api/forum/
packages/forum/
packages/ai/moderation/
packages/ai/summarizer/

2. Database Models (Drizzle ORM)

Add / update the following models (Postgres):

threads — id, title, body, author_id, category, created_at, updated_at, pinned, ai_summary, likes_count, reply_count

replies — id, thread_id, author_id, body, created_at, updated_at, ai_flags, toxicity_score

categories — id, name, description, thread_count

user_reputation — user_id, karma_points, badges[]

reports — id, target_type (thread|reply), target_id, reporter_id, reason, ai_confidence, status (open/resolved)

mod_actions — id, moderator_id, action, target_type, target_id, notes, created_at

Ensure all models are properly related (foreign keys, cascades).

💬 API Endpoints

Thread Management

POST /api/forum/thread → create thread (authenticated)

GET /api/forum/threads → list by category with pagination

GET /api/forum/thread/[id] → full thread with replies

POST /api/forum/thread/[id]/reply → add reply

PATCH /api/forum/thread/[id]/pin → admin only

DELETE /api/forum/thread/[id] → author or admin

AI Moderation

POST /api/forum/moderate
Uses internal packages/ai/moderation.ts to evaluate text toxicity, hate, profanity, spam, self-promo, etc.
(see below for model sources)

AI Summarization

POST /api/forum/summarize
When thread exceeds 15 replies, auto-summarize discussion into 3-line “AI Summary” shown under the thread title.
Uses local lightweight transformer or free endpoint (see below).

Reports

POST /api/forum/report → user reports content

GET /api/forum/reports → moderators list reports

PATCH /api/forum/report/[id]/resolve → mark resolved

🤖 AI Integrations (Free/Open)
Moderation Model (free)

Use Hugging Face inference API (free-tier):

model: unitary/toxic-bert
endpoint: https://api-inference.huggingface.co/models/unitary/toxic-bert


Function: analyzeTextForToxicity(text)
→ returns object { toxicity_score, flagged_terms[], decision: "allow"|"review"|"reject" }

Rate-limit to 10 req/min per IP.
Cache results per hash of text for 24h.

Summarization Model (free)

Use:
https://api-inference.huggingface.co/models/facebook/bart-large-cnn
Function: summarizeThread(threadText)
→ returns short summary.

Fallback: local extractive summarizer (tf-idf + keyword clustering) if API fails.

🛡️ Moderation Logic

AI + Human Hybrid

Every post passes through moderation model (toxic-bert).

If toxicity > 0.8 → reject

0.4–0.8 → send to moderator queue

<0.4 → auto-publish

Moderator view shows AI confidence, flagged words, and decision history.
