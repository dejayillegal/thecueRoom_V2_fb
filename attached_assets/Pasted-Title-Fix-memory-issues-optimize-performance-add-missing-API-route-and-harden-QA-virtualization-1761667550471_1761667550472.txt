3) Specific performance improvements to implement
- Virtualize large lists (forum threads, news feed).
- Memoize heavy components with React.memo and useCallback/useMemo for props.
- Replace expensive CSS paint triggers with composite-only transforms:
  - For hovering, use `transform: translateY()` and `opacity` rather than margins/paddings that cause reflow.
  - Add `will-change: transform, opacity` sparingly.
- Use `position: sticky` for Sidebar and Header; remove JS scroll handlers where possible.
- Offload heavy parsing (RSS -> normalized objects) to a Web Worker on client; on server, use background worker process (scripts/worker-dev-setup.sh) and queue.
- Ensure single websocket subscription pattern (use shared socket hook).
- Debounce filter/search inputs (300ms) and throttle scroll event handlers (use passive listeners).
- Use `loading="lazy"` for images and `priority` for hero images only.
