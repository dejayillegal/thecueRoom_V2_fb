
# Unit Tests

Unit tests for individual functions, components, and utilities using Vitest and React Testing Library.

## Coverage Target

- Core modules: ≥ 80% coverage
- Auth flows: 100% coverage
- Playlist worker: ≥ 90% coverage
- Critical utilities: 100% coverage

## Running Tests

```bash
pnpm test:unit
pnpm test:unit:coverage
pnpm test:unit:watch
```

## Coverage Report

Coverage reports are generated at `coverage/index.html`
