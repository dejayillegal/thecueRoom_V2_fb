# **App Name**: thecueRoom

## Core Features:

- Feed Display: Display aggregated content (posts, memes, news) in a reverse chronological feed. Content types include text, images, video, and audio.
- Meme Generation: Allow users to input a text prompt to generate meme images, leveraging a generative AI tool.
- News Aggregation: Aggregate news from provided RSS feeds, categorized by genre and region.
- Gig Radar Display: Display a map showing nearby venues and gigs, allowing users to RSVP and save gigs to their profile.
- EPK Export: Enable artists to export an EPK (Electronic Press Kit) in PDF format, adhering to the defined style guidelines.
- Profile Management: Allow users to customize their profile with an artist banner and showcase their feed, gigs, tracks, and memes.
- Admin Content Moderation: Provide an admin console to moderate user-generated content, approve/reject flags, and review evidence.

## Style Guidelines:

- Primary background color: Dark grey (#0B0B0B) for a modern, sophisticated feel.
- Surface panels color: Slightly lighter grey (#111111) to create visual layers.
- Primary CTA color: Neon lime (#D1FF3D) for high-impact calls to action. The selection of neon lime for calls to action and key UI elements provides vibrancy against a darker background. It intends to modernize the visual and signal action without depending on more cliche invocations of modernity, such as gradients.
- Accent color: Purple (#873BBF) used sparingly to highlight specific elements.
- Headline font: 'Inter Black' (sans-serif) for bold and clear headings.
- Body font: 'Inter Regular' (sans-serif) for readable content.
- Code/UI font: 'Source Code Pro' (monospace) for code snippets and UI elements.
- Use a consistent style of icons throughout the app to represent different sections and actions. Neon outlines could work well with the overall theme.
- Implement a grid-based layout for consistent spacing and alignment of elements. Consider using a dark grid theme as one of the theme options.
- Employ subtle animations for transitions and interactions, respecting user preferences for reduced motion. Implement a beat-synced pulse animation, particularly for music-related content.
